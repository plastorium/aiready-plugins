# Businesses, profile, competitors and topics

Detail for the `understand-my-business` skill; scopes are in [mcp-workflows.md](../../aiready/references/mcp-workflows.md).

- `business_add` takes the website. It returns the existing business when the site is already there (never a second one), starts no enrichment or measurement and spends nothing. When the person belongs to several organizations it refuses with the choices; ask, then pass the one they pick as `organizationId`, and only that organization's businesses count as already there, so a site another organization has can be added to theirs.
- `business_correct`: only the facts the person asked to change (an industry correction must not touch languages, location or competitors). Facts: display `name` (not the brand name), brand and legal name, industry, main service, main `address` / `phone` / `email`, primary location, languages, call tracking (`usesCallTracking: true` when listings show tracking phone numbers, so phone consistency is not checked). Audiences and jobs to be done are `audiences` and `jobs` on the same tool (ADR-309 D6): each named one is merged by name or title, so the others stay; send them as their own correction; it saves at once. They do not change the questions AIReady already asks. The jobs are used the next time questions are generated (the first eight, in order); the audiences are kept on the profile for now, and a job past the eighth is refused. A fact's text the person states goes in a fact-edit change (facts-profile-listings.md). A list of changes saves at once, without asking first; the result shows each change before and after, removals marked, and what future checks will change: report that. Profile sections (facts-profile-listings.md) apply the whole profile in the same way. The kind of business (`productType`, `isLocalBusiness`, `businessType`) changes which checks run, so it goes through `measurement_settings_update`, on the AIReady Advanced connector only, and runs at once (report the cost per scan after); on this connector, tell the person the step needs Advanced. The folder a project sits in is set on the web (or the AIReady Advanced connector).
- `locations_change` (AIReady Advanced only, and the partner API; on this connector, say the step needs AIReady Advanced or the project's location settings): business locations (`addBusinessLocations`, `updateBusinessLocations` by id, `removeBusinessLocations`) and market locations (`updateLocationSets` to rename or switch set A/B/C on or off, `addMarketLocations` with a `label` such as "Austin, TX", `removeMarketLocations`). Ids come from `business_profile` (`businessLocations`, `marketLocationSets`). One call can batch several changes; adding or changing runs at once and returns its effect (counts before → after, cost note); a batch that removes something returns a `confirmUrl` for the person to confirm on the AIReady page. A Google Business Profile link must be a Google Maps place link; one that cannot be verified is saved without the verified mark — say so.
- `project_delete` (AIReady Advanced connector only; on this connector say deleting a business needs Advanced): only when the person asks to delete the business; name it back, and note it needs the admin or owner role and cannot be restored.

## Competitors

- `competitors` (view all, tracked, suggested or in_answers; declined or promoted for what the person turned down or tracked from a suggestion) reads every store to the end; a name in its results is what the person means only when it matches one business.
- `competitors_track` tracks the competitors the person names (by name, website or a suggestion) or locks one (`lock: true`) so it stays in every comparison. It runs at once; adding raises every later comparing scan's cost, so say so after.
- "Not my competitor" is a rejection that lasts: `competitors_decline` with the name, website or id. It stops tracking it or declines the suggestion wherever it is (one business can sit in several places at once; the server handles every one) and records the decline, so discovery does not suggest it again. Removing a tracked competitor runs at once too; say it is out of later comparisons. Candidates → ask which business, never pick.
- Registry fixes (rename, split, merge a duplicate, restore a declined one) and finding more competitors: the tools in [feature-benchmarks.md](../../compare-competitors/references/feature-benchmarks.md).

## Topics

- `prompts` shows the questions and the topics they cover; `topics_tracking` starts (`track`) or stops (`untrack`) tracking the topics the person names, by name or id, on their word; `dismiss` takes one they do not want out of auto-generated questions from the next scan (a location's dismissal changes only the topic map), and `activate` brings a dismissed one back. Each topic goes in one list per call. Nothing is spent or deleted. Whether new topic suggestions wait for review (the acceptance mode) is set on the web Topic Map or the AIReady Advanced connector.
- Reviewing the topic map in detail is on the AIReady Advanced connector only (and the web Topic Map). On this connector, say a step below needs Advanced; never call these tools here.
- Manual topics (AIReady Advanced): `manual_topic_create`, `manual_topic_update` (rename, re-seed, move), `manual_topic_delete` (children move up; no restore). Create and update run at once and rebuild the topic map (cost): say so after. A delete returns a `confirmUrl` for the person to confirm on the AIReady page.
- Suggested topics (AIReady Advanced): `topic_suggestions` (pending by default; source, search demand, keywords — untrusted) → on the person's word `topic_suggestion_promote` (adds it as a manual topic, optional parent; rebuilds the map; runs at once, say the cost after) or `topic_suggestion_dismiss` or `topic_suggestion_merge` (into another pending one; both final, so each returns a `confirmUrl` for the person to confirm on the AIReady page).
- Auto-groups and placement (AIReady Advanced): `topic_groups` → `topic_group_promote` (`macroIds`, or `source` for all of one kind; one group may get a `name` / parent) makes them manual topics. `topic_placement` moves topics under a manual topic (`move` / `merge`), keeps them top-level (`exclude`) or undoes that (`unassign`). Both run at once and rebuild the map: say so after.
- Unmapped phrases from answers (AIReady Advanced): `prompt_mapping_queue` → `prompt_mapping_decide` (`promote` to a pending suggestion, `map` with `targetKey`, or `dismiss`; one decision per phrase).
